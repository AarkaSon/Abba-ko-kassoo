# Presentation assets

`iitbbs_logo_official.png` is a high-resolution rasterization of the IIT Bhubaneswar emblem used at the upper-right of every slide.

The emblem was checked visually against the institute website (`https://www.iitbbs.ac.in/`). The vector used for rasterization was retrieved from the public GitHub repository `Subham170/IR_Conclave_2024` (`src/assets/Indian_Institute_of_Technology_Bhubaneswar_Logo.svg`). For formal external publication, the institute's current communications/IP master artwork should take precedence.

`crash_barrier_hud_hero.png` is an original AI-generated concept visual prepared for the title slide. It depicts a highway crash barrier with a futuristic engineering HUD/cutaway and contains no third-party logos or copyrighted film interface artwork.
